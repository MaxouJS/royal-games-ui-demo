# royal-games-ui-demo

Documentation and live examples for
[`@objectifthunes/royal-games-ui`](https://www.npmjs.com/package/@objectifthunes/royal-games-ui) —
the Midnight Court UI kit for Capacitor mobile games.

Live: https://maxoujs.github.io/royal-games-ui-demo/

- Next.js static export, deployed to GitHub Pages by `.github/workflows/pages.yml`.
- Global ENAMEL / GLOSS skin toggle and a ▶ MOTION replay control.
- Component pages with live previews and source; full phone screens under `/screens`.

```bash
pnpm install
pnpm dev
```
